# WATERLINE V39 — CANON + FUNCTIONAL BUILD

이 버전은 이전 기능을 유지하면서 WATERLINE의 확정 세계관과 충돌하던 메인 미스터리/기억 설정을 제거한 기준본이다.

## 유지된 기능
- 1인 플레이 + 방 코드 기반 멀티 구조
- 저택 방 이동
- 저택 방 내부 물건 직접 조사
- 저택 생활 행동/자원 관리/방 해금
- 도시 장소 이동 및 지도
- 도시 장소별 조사
- NPC 대화 및 관계도
- 선택지 트리와 선택 결과
- 반복 가능한 일일 사건
- 시간/날짜 진행과 자유생활
- 운하 살롱 포커/바카라 미니게임
- 사건 기록/가방/로그
- 도시 확장 지역

## WATERLINE 캐논
도시의 절반은 수면 위, 나머지는 수면 아래에 존재한다. 수몰된 건물도 방수가 잘 되어 생활 공간으로 사용된다. 변이동물은 특별한 괴물이 아니라 도시 생활의 일부다. 외곽의 오래된 저택에는 아이 두 명과 거대한 변이동물이 산다. 거대한 변이동물은 고아원에서 떠내려온 두 개의 나무바구니를 발견해 아이들을 아기 때부터 길렀다.

메인 스토리의 구체적인 사건은 아직 확정하지 않았으며, 다른 세계관의 기억/합성 기억 설정을 가져오지 않는다.
